# UfloPropertyPlaceholderConfigurer

## 概述

UfloPropertyPlaceholderConfigurer 是 UFLO 工作流引擎的属性占位符配置器，继承自 Spring 的 PropertySourcesPlaceholderConfigurer。它负责处理应用程序中的属性占位符，使配置文件中的占位符能够被正确解析和替换。

## 类信息

- **包路径**: com.bstek.uflo
- **继承关系**: 继承 Spring 的 PropertySourcesPlaceholderConfigurer
- **作者**: Jacky.gao
- **创建时间**: 2016年5月25日

## 功能特性

### 1. 属性占位符解析
- 解析配置文件中的 ${...} 占位符
- 从多个属性源中查找并替换属性值
- 支持嵌套属性和复合属性

### 2. 容错配置
- 设置 `ignoreUnresolvablePlaceholders(true)` 表示忽略无法解析的占位符
- 当属性无法解析时不会抛出异常，而是保留原始占位符
- 提高系统的容错性和鲁棒性

### 3. 加载优先级
- 设置配置器优先级为 100
- 控制属性解析的执行顺序
- 确保在其他组件初始化前完成属性解析

- 提供属性的集中管理机制

## 配置参数

### ignoreUnresolvablePlaceholders
- **功能**: 控制是否忽略无法解析的占位符
- **值**: true
- **效果**: 无法解析的占位符不会导致启动失败

### order
- **功能**: 设置配置器的执行顺序
- **值**: 100
- **效果**: 控制在多个配置器中的执行优先级
