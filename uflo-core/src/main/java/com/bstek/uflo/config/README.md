# Config 包 (com.bstek.uflo.config)

## 概述

Config 包负责 UFLO 工作流引擎的配置管理和自动配置功能。它利用 Spring Boot 的自动配置机制，简化了 UFLO 引擎的集成和配置过程。

## 包结构

- `com.bstek.uflo.config`
  - 自动配置类和配置属性定义

## 核心类

### UfloProperties
定义了 UFLO 引擎的各种配置属性，包括：
- 数据库配置参数
- 工作流引擎行为配置
- 性能参数配置
- 安全配置选项

### UfloCoreConfiguration
核心配置类，负责：
- 初始化工作流引擎所需的各种组件
- 配置工作流服务
- 设置数据源和事务管理器
- 配置表达式解析器

### UfloAutoConfiguration
Spring Boot 自动配置类，使用 `@EnableAutoConfiguration` 注解，自动配置 UFLO 引擎所需的各种组件，包括：
- 命令服务
- 流程服务
- 任务服务
- 历史服务
- 环境配置

## 设计模式

### 配置模式
- **目的**: 集中管理应用程序的配置参数
- **优点**:
  - 配置集中管理，便于维护
  - 支持外部化配置
  - 类型安全的配置访问

### 自动配置模式
- **目的**: 基于类路径和配置自动创建和配置组件
- **优点**:
  - 减少手动配置工作
  - 根据条件自动启用/禁用功能
  - 提供合理的默认值

## 配置内容

### 引擎配置
- 流程定义缓存策略
- 任务调度配置
- 历史数据保存策略
- 并发控制参数

### 数据库配置
- 数据源配置
- 连接池参数
- 数据库方言设置
- 事务管理配置

### 表达式配置
- 表达式语言设置
- 自定义函数配置
- 变量解析策略

### 安全配置
- 权限控制参数
- 认证方式设置
- 加密配置

## 配置机制

### 外部化配置
支持以下配置来源：
1. application.properties/yml
2. 环境变量
3. 命令行参数
4. 配置文件

### 配置优先级
配置优先级从高到低：
1. 命令行参数
2. 系统属性 (System.getProperties())
3. 操作系统环境变量
4. application.properties/yml 文件

## 扩展性

Config 包设计具有良好的扩展性：
- 支持自定义配置属性
- 可通过配置文件自定义引擎行为
- 允许注册额外的配置类
- 支持条件化配置（基于环境条件启用特定配置）

## 集成方式

通过 Spring Boot 自动配置机制，只需在项目中添加依赖，即可自动配置：
- 自动检测并配置数据源
- 自动创建流程引擎相关组件
- 自动配置事务管理器
- 自动设置工作流服务
