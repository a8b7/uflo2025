# Expression 包 (com.bstek.uflo.expr)

## 概述

Expression 包负责工作流引擎中的表达式解析和计算功能。它提供了一套灵活的表达式语言系统，用于在流程定义中动态计算变量值、条件表达式和业务逻辑。

## 包结构

- `com.bstek.uflo.expr`
  - `impl` - 表达式功能的具体实现类

## 核心类与接口

### ExpressionProvider
表达式提供者接口，定义表达式解析和计算的抽象方法：
- 解析表达式字符串
- 计算表达式的值
- 提供表达式上下文管理
- 支持不同的表达式语言

### ExpressionContext
表达式上下文类，提供表达式计算所需的环境：
- 变量访问接口
- 函数注册和管理
- 作用域管理
- 类型转换机制

## 设计模式

### 解释器模式
- **目的**: 用于解析和执行表达式语言
- **应用**:
  - 解析表达式语法树
  - 执行表达式计算
  - 处理变量引用和函数调用

### 策略模式
- **目的**: 支持多种表达式语言策略
- **应用**:
  - 不同的表达式解析策略
  - 可配置的表达式引擎

### 工厂模式
- **目的**: 创建和管理表达式解析器实例
- **应用**:
  - 表达式解析器的创建
  - 表达式引擎的初始化

## 表达式功能

### 1. 变量解析
- 访问流程变量
- 访问系统变量
- 支持复杂的对象属性访问
- 变量类型自动转换

### 2. 函数支持
- 内置函数库（字符串、数学、日期等）
- 自定义函数注册
- 函数参数验证
- 函数执行安全控制

### 3. 运算符支持
- 算术运算符（+、-、*、/、%）
- 关系运算符（>、<、==、!=）
- 逻辑运算符（&&、||、!）
- 条件运算符（三元运算符）

### 4. 语法特性
- 支持括号分组
- 支持链式属性访问
- 支持集合操作
- 支持条件表达式

## 执行上下文

### 变量作用域
- 全局作用域：所有流程共享的变量
- 流程作用域：当前流程实例的变量
- 任务作用域：当前任务的局部变量
- 临时作用域：表达式执行期间的临时变量

### 安全控制
- 变量访问权限控制
- 沙箱执行环境
- 防止恶意代码执行
- 资源使用限制
