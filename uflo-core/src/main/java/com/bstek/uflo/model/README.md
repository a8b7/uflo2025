# Model 包 (com.bstek.uflo.model)

## 概述

Model 包定义了工作流引擎中的核心数据模型和实体类。这些模型类映射到数据库表结构，用于持久化和管理流程定义、流程实例、任务等核心工作流数据。

## 包结构

- `com.bstek.uflo.model`
  - `calendar` - 日历相关模型
  - `task` - 任务相关模型
  - `variable` - 变量相关模型
  - 核心模型实体类

## 核心模型类

### ProcessDefinition（流程定义）
表示流程定义的模型类：
- 包含流程的元数据信息
- 定义流程的结构和行为
- 版本控制和部署信息
- 流程分类和权限配置

### ProcessInstance（流程实例）
表示流程实例的模型类：
- 运行中的流程实例数据
- 当前执行状态和位置
- 流程变量和上下文
- 启动参数和执行历史

### HistoryProcessInstance（历史流程实例）
表示历史流程实例的模型类：
- 已完成或终止的流程实例
- 执行统计和时间信息
- 业务关联数据
- 历史性能指标

### Activity（活动）
表示流程中活动节点的模型类：
- 流程执行过程中的活动状态
- 当前执行的节点信息
- 活动的生命周期管理
- 执行路径和分支信息

### HistoryActivity（历史活动）
表示历史活动的模型类：
- 已完成的活动记录
- 执行时间和耗时统计
- 活动执行结果
- 活动相关的审计信息

### HistoryTask（历史任务）
表示历史任务的模型类：
- 已完成的任务记录
- 任务执行统计
- 执行者信息
- 任务时间线信息

### HistoryVariable（历史变量）
表示历史变量的模型类：
- 历史流程变量记录
- 变量值变更历史
- 变量类型信息
- 变量作用域信息

### Blob 和 HistoryBlob
二进制大对象模型：
- 存储大文本或二进制数据
- 用于附件或大型数据的持久化
- 历史版本的 BLOB 数据

### Heartbeat
心跳记录模型：
- 记录工作流引擎实例的心跳信息
- 实例状态和健康指标
- 活跃时间戳
- 集群实例管理

### ContextProperty
上下文属性模型：
- 存储引擎的配置属性
- 系统级参数设置
- 运行时配置信息
- 环境属性管理

## 设计模式

### 活动记录模式
- **目的**: 将数据表的行映射为对象
- **应用**:
  - 实体类直接映射数据库表
  - 提供数据访问的方法

### 值对象模式
- **目的**: 代表一个简单的值而不是唯一标识
- **应用**:
  - 变量模型中的值对象
  - 简单数据传输对象

### 分层架构
- **目的**: 分离不同类型的模型
- **应用**:
  - 当前模型与历史模型分离
  - 核心模型与扩展模型分离

## 持久化机制

### JPA 注解
- 使用 `@Entity` 标记实体类
- 使用 `@Table` 定义表映射
- 使用 `@Column` 定义列映射
- 使用 `@Id` 定义主键
- 使用 `@JoinColumn` 定义关联关系

### 关联关系
- 一对多关系（流程定义与流程实例）
- 一对一关系（实例与当前活动）
- 多对一关系（任务与实例）

## 模型分类

### 现行模型
- ProcessDefinition, ProcessInstance, Activity 等
- 表示当前活动的流程状态
- 支持 CRUD 操作

### 历史模型
- HistoryProcessInstance, HistoryActivity, HistoryTask 等
- 记录已完成的流程活动
- 用于审计和报表

### 任务模型
- 包含任务分配、状态、优先级等信息
- 支持任务的各种操作类型

### 变量模型
- 管理流程变量的存储和访问
- 支持不同数据类型的变量
