# Process 包 (com.bstek.uflo.process)

## 概述

Process 包是 UFLO 工作流引擎的核心包之一，负责处理工作流的执行逻辑，包括流程定义、节点处理、任务分配、流程流转等功能。

## 包结构

- `com.bstek.uflo.process`
  - `assign` - 任务分配相关功能
  - `flow` - 流程流转逻辑
  - `handler` - 流程节点处理逻辑
  - `listener` - 流程和任务事件监听器
  - `node` - 流程节点定义和实现
  - `security` - 流程安全控制
  - `swimlane` - 泳道定义和管理

## 核心模块

### Node（节点模块）
定义各种流程节点类型：
- `StartNode` - 开始节点
- `EndNode` - 结束节点
- `TaskNode` - 任务节点
- `DecisionNode` - 决策节点
- `ForkNode` - 分叉节点
- `JoinNode` - 汇聚节点
- `SubprocessNode` - 子流程节点
- `ActionNode` - 动作节点
- `ForeachNode` - 循环节点

### Assign（任务分配模块）
处理任务分配逻辑：
- `Assignee` - 任务分配基本接口
- `AssigneeProvider` - 任务分配提供者
- `Entity` - 分配实体
- `PageQuery` - 分页查询类

### Listener（监听器模块）
提供事件监听机制：
- `ProcessListener` - 流程事件监听器
- `TaskListener` - 任务事件监听器
- `GlobalTaskListener` - 全局任务监听器

## 核心类与接口

### Node
流程节点的抽象基类，定义节点的基本属性和行为：
- 节点标识和名称
- 输入输出连接
- 节点执行逻辑
- 节点属性配置

### NodeType
定义流程节点类型枚举：
- START - 开始节点
- END - 结束节点
- TASK - 任务节点
- DECISION - 决策节点
- FORK - 分叉节点
- JOIN - 汇聚节点
- 等等

### DecisionType
决策节点类型枚举，支持多种决策策略：
- EXPRESSION - 表达式决策
- SCRIPT - 脚本决策
- 等等

### SubprocessType
子流程类型枚举，定义子流程的执行方式：
- EMBEDDED - 嵌入式子流程
- CALL - 调用式子流程

### AssignmentType
任务分配类型枚举，定义任务分配策略：
- EXPRESSION - 表达式分配
- SCRIPT - 脚本分配
- STATIC - 静态分配

### ProcessListener
流程监听器接口，提供流程生命周期事件的监听：
- 流程启动事件
- 流程结束事件
- 节点进入事件
- 节点退出事件

### TaskListener
任务监听器接口，提供任务生命周期事件的监听：
- 任务创建事件
- 任务分配事件
- 任务完成事件
- 任务取消事件

## 设计模式

### 状态模式
- **目的**: 根据流程执行状态执行不同的行为
- **应用**:
  - 不同节点类型的不同处理逻辑
  - 流程实例状态管理

### 策略模式
- **目的**: 支持不同的节点执行策略和任务分配策略
- **应用**:
  - 不同类型的决策节点
  - 多种任务分配算法

### 观察者模式
- **目的**: 监听流程和任务的执行事件
- **应用**:
  - ProcessListener 和 TaskListener
  - 全局事件监听

### 模板方法模式
- **目的**: 定义节点执行的标准流程，允许子类自定义特定步骤
- **应用**:
  - 节点执行流程的标准化
  - 允许自定义特定节点行为

## 流程执行机制

### 1. 节点执行
- 节点进入逻辑处理
- 节点业务逻辑执行
- 节点退出逻辑处理
- 下一节点流转

### 2. 任务分配
- 根据分配规则确定任务处理人
- 支持静态分配和动态分配
- 支持表达式和脚本分配
- 支持会签和协作任务

### 3. 流程流转
- 基于条件的路径选择
- 支持并行和串行流转
- 异常处理和回退机制
- 流程跳转和转办

### 4. 事件处理
- 流程事件的触发和监听
- 任务事件的触发和监听
- 自定义事件处理逻辑
- 事件传播和处理

## 任务分配机制

### 分配策略
- 静态分配：直接指定处理人
- 表达式分配：通过表达式计算处理人
- 脚本分配：通过脚本动态确定处理人
- 委托分配：委托给其他用户处理

### 分配对象
- 个人任务：分配给具体用户
- 角色任务：分配给角色下的所有用户
- 群组任务：分配给用户群组
- 候选任务：多个用户可认领的任务
