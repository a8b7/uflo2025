# Query 包 (com.bstek.uflo.query)

## 概述

Query 包提供了工作流引擎的数据查询功能，包括流程定义、流程实例、任务、历史记录等各类数据的查询操作。采用链式调用的设计模式，提供了灵活和强大的查询能力。

## 包结构

- `com.bstek.uflo.query`
  - `impl` - 查询接口的具体实现类

## 核心类与接口

### Query
查询接口的基类，定义了所有查询操作的通用方法：
- 分页查询支持
- 排序功能
- 计数查询
- 结果返回方法

### ProcessQuery
流程定义查询接口，提供对流程定义的查询操作：
- 按流程定义ID查询
- 按流程定义KEY查询
- 流程名称、版本、状态查询
- 分页和排序支持

### ProcessInstanceQuery
流程实例查询接口，提供对运行中流程实例的查询操作：
- 按流程实例ID查询
- 按流程定义查询
- 按业务键查询
- 按创建用户查询
- 按执行状态查询

### TaskQuery
任务查询接口，提供对任务的查询操作：
- 按任务ID查询
- 按任务处理人查询
- 按任务候选人查询
- 按任务分配组查询
- 按任务名称、优先级、创建时间等查询

### HistoryProcessInstanceQuery
历史流程实例查询接口，提供对已完成流程实例的查询操作：
- 按流程实例ID查询
- 按结束时间查询
- 按持续时间查询
- 按业务键查询

### HistoryTaskQuery
历史任务查询接口，提供对已完成任务的查询操作：
- 按任务ID查询
- 按任务处理人查询
- 按结束时间查询
- 按持续时间查询

### ProcessVariableQuery 和 HistoryProcessVariableQuery
流程变量查询接口，提供对流程变量的查询操作：
- 按变量名称查询
- 按变量值查询
- 按变量类型查询
- 按变量作用域查询

### QueryJob
查询任务类，用于执行复杂的查询操作。

## 设计模式

### 建造者模式
- **目的**: 通过链式调用构建复杂的查询条件
- **应用**:
  - 查询条件的逐步构建
  - 灵活的查询参数设置

### 模板方法模式
- **目的**: 定义查询执行的通用流程
- **应用**:
  - 标准化查询执行过程
  - 允许子类自定义特定步骤

### 策略模式
- **目的**: 支持不同的查询策略和算法
- **应用**:
  - 不同数据类型的查询策略
  - 不同排序策略

## 查询功能

### 1. 条件查询
- 等值条件：等于、不等于
- 模糊条件：LIKE 操作
- 范围条件：大于、小于、介于
- 空值条件：为空、非空

### 2. 排序功能
- 单字段排序
- 多字段排序
- 升序/降序支持
- 动态排序条件

### 3. 分页支持
- 限制返回结果数量
- 跳过指定数量的记录
- 支持大数据量的分页查询

### 4. 聚合查询
- 计数查询
- 统计功能
- 分组查询支持

## 使用模式

### 链式调用
```java
List<Task> tasks = taskQuery()
    .assignee("userId")
    .taskNameLike("%审批%")
    .orderByTaskCreateTime()
    .desc()
    .listPage(0, 20);
```

### 分页查询
- 支持指定查询起始位置和数量
- 提供总数统计功能
- 适用于大数据量场景

### 结果处理
- 返回列表结果
- 返回单个对象
- 返回计数结果
- 自定义结果映射
