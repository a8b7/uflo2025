# Utils 包 (com.bstek.uflo.utils)

## 概述

Utils 包提供了工作流引擎所需的各种通用工具类和辅助函数。这些工具类封装了常见的操作和算法，提高了代码的复用性和开发效率。

## 包结构

- `com.bstek.uflo.utils`
  - 通用工具类和辅助函数

## 核心类与功能

### Utils
通用工具类，提供了各种常用的辅助方法：
- 字符串处理函数
- 集合操作工具
- 类型转换工具
- 对象操作工具
- 反射操作工具

### EnvironmentUtils
环境工具类，提供环境相关操作：
- 环境变量访问
- 系统属性获取
- 环境配置检查
- 运行时环境管理

### IDGenerator
ID生成器接口，定义ID生成策略：
- 提供唯一的ID生成方法
- 支持分布式ID生成
- 确保ID的唯一性和有序性

### ModernIDGenerator
ID生成器的现代化实现，基于当前技术栈实现ID生成算法：
- 高效的ID生成策略
- 支持高并发ID生成
- 分布式环境下的ID唯一性保证

### ProcessListenerUtils
流程监听器工具类，提供监听器操作的辅助方法：
- 监听器执行的统一处理
- 事件传播支持
- 监听器生命周期管理
- 异常处理和恢复

### Splash
启动画面或加载提示相关工具类，用于系统初始化过程中的展示：
- 启动信息展示
- 初始化进度反馈
- 系统加载状态管理

## 设计模式

### 工具类模式
- **目的**: 提供可复用的功能函数
- **应用**:
  - 静态方法集合
  - 无状态的工具函数

### 工厂模式
- **目的**: 创建ID生成器实例
- **应用**:
  - IDGenerator 的实现选择
  - 策略模式的实现

### 单例模式
- **目的**: 确保某些工具的唯一性
- **应用**:
  - ID生成器实例管理
  - 环境管理工具
